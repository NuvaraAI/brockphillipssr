# Nuvara Media

**Private newsroom and production implementation · Editorial work in development**

[← Project index](README.md) · [Published writing](the-crowned-one.md)

A media workflow needs to track what a claim is based on, what assets can be used, which version was reviewed, and whether publication actually happened. Nuvara Media connects those questions to production records and tools.

## My contribution

I developed the editorial direction, programming plans, evidence standards, and release requirements. I directed AI-assisted implementation of the newsroom and local production pipeline, including review of technical samples and their limitations.

## What was built

- Programming and rundown records, script/scene versions, and source/rights ledgers.
- Distinctions between factual claims, quotations, opinion, and fiction.
- Corrections and approval invalidation when a reviewed version changes.
- Offline transcription and local drafting workflows.
- FFmpeg rendering with captions, source/correction treatments, thumbnails, metadata, and provenance.
- Hashed resumable stages, cancellation, and shared-compute/resource boundaries.
- Provider receipts that preserve uncertain submissions and separate preparation from publication.

The reviewed work uses Node.js/TypeScript, SQLite, FFmpeg, offline MLX Whisper, and local Qwen workflows. Private footage, voice records, and original source material are excluded here.

## Evidence and status

October 6–7 implementation reports retain scoped test results and technical export checks. The programming register contains **31 entries**; that is a planning inventory, not 31 completed shows. Technical samples and two short private editorial candidates were produced.

Some provider acceptance used simulations. A later 20-minute technical export demonstrates resumable rendering within its test conditions; it does not establish an accepted full-length spoken program or audience impact.

The newsroom implementation is real, while a completed public programming slate, final rights/editorial acceptance, and reliable full-length delivery remain separate work. My published paperback is documented independently in its own case study.

**Skills demonstrated:** editorial systems, provenance, media workflow design, local production, resumability, resource controls, release review, accurate status reporting.
