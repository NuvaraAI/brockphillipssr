The approach

People define the purpose. Evidence establishes the result.

I start with the person, the task, and the constraints. I use tools to build and check the work, preserve source evidence, document corrections, and keep consequential decisions with the human owner.

How I handle evidence ↗
01

Understand the work

Connect the product to the actual task, the people using it, and the constraints they face.

02

Make the result inspectable

Preserve sources, versions, checks, and outcomes so someone else can assess the work.

03

Keep people in control

Separate preparation, permission, execution, and verification in consequential workflows.
